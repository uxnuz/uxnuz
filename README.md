# PUBG 전략 피드백 맵

PUBG(배틀그라운드) 맵 캡처에 전략 피드백을 표시하는 웹 도구입니다. 브라우저에서만 동작하는 정적 사이트로, 서버 없이 GitHub Pages에서 바로 실행됩니다.

## 기능

지도 캡처 이미지를 업로드한 뒤 사이드바 도구로 아래 표시를 추가할 수 있습니다.

1. 연막탄 아이콘
2. 수류탄 투척 지점 아이콘
3. 이동 동선 (점선, 클릭으로 점을 추가)
4. 적 위치 아이콘
5. 삼각형 모양 엄폐물 아이콘 (클릭 후 드래그로 방향 지정)

완성된 맵은 `PNG로 내보내기` 버튼으로 다운로드해 공유할 수 있습니다.

## 로컬 실행

빌드 과정이 필요 없습니다. `index.html`을 브라우저로 열면 바로 사용할 수 있습니다.

```
start index.html
```

## 배포

GitHub Pages로 배포되어 있습니다.
