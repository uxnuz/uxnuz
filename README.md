# PUBG feedback

다시보기로 카메라 열심히 이동해가면서 피드백하지 말고 맵 캡처 하나 찍어서 ㄱㄱ

## 기능

컨트롤 + z
스크롤로 확대/축소
우클릭으로 확대한 상태에서 지도 이동
맵 캡처 화질 깨지니까 win + shift + s 보다는 알캡처 같은걸로 캡처해서 쓰는걸 추천

## 로컬 실행

빌드 과정이 필요 없습니다. `index.html`을 브라우저로 열면 바로 사용할 수 있습니다.
