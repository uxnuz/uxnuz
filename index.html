키 가이드

보기 / 탐색

  • 마우스 스크롤 — 커서 위치 기준으로 지도 확대/축소
  • 우클릭 드래그 — 화면 이동(패닝)
  • Shift + 스크롤 (아이콘 위, "Shift+휠 크기조절" 토글 ON) — 그 아이콘만 크기 조절

표시 추가

  • 클릭 — 적 위치 / 바위 / 나무 / 팀원 1~4 배치
  • 클릭 후 드래그 — 연막탄 / 수류탄 투척 (뗀 지점에 생성, 점선으로 투척 경로 표시)
  • 클릭 후 드래그 — 차량 / 긴엄신 방향을 360도로 지정
  • 클릭한 채로 드래그 — 이동 동선(직선/자유선), 사격선 그리기

편집

  • Ctrl + Z — 실행취소
  • Esc — 그리는 중인 선/방향 지정 취소
  • 선택/삭제 도구 + 클릭 — 마커 삭제
  • 전체 지우기 버튼 — 모든 표시 삭제

기타

  • Ctrl + V — 클립보드에 복사한 이미지를 지도로 붙여넣기
  • 투명도 슬라이더 — 아이콘/이펙트 투명도 조절 (지도 이미지는 영향 없음)
  • PNG로 내보내기 — 현재 확대/이동 상태와 무관하게 전체 지도를 원본 해상도로 저장
